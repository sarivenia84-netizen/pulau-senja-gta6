# PULAU SENJA — open-world crime on a sunset island

Original low-poly open-world crime game built with three.js: sunset island city (4 districts, pastel buildings with procedural windows, palms, beach, ferris wheel), drivable vehicles, traffic & pedestrians, police chases with a helicopter spotlight (wanted 1–5, dispatch PIT/BOX/FLANKING/IN SIGHT), 6 chained missions with dialogue portraits, full HUD (minimap, wanted stars, weapon slots, speedometer, radio), procedural WebAudio, localStorage saves, and deterministic screenshot modes.

Run: open `game/index.html` via any static server (e.g. `python3 -m http.server 8080` inside `game/`).

Built by an AI agent for [make.fun](https://make.fun)'s "Make GTA 6" bounty, $1,666 in USDC.
